# What's this?

Story is a visual novel engine like Ren'Py but based on golang [ebiten](github.com/hajimehoshi/ebiten). 

# Why another game engine?

For Go programmers, it should be easier to use Golang than learning Python or a specialized script language designed for visual novel only.
And Ren'Py shows low protection for game resources such as code, pictures or videos, and it's BIG.
